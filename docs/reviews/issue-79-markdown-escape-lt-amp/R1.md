## 指摘

### [R1-1][Medium][plugins/saai-knowledge/includes/class-markdown-converter.php:338]

`\<` / `\&` のバックスラッシュエスケープは CommonMark 系（markdown-it・commonmark.js・remark・marked）でしか効かない。Markdown.pl・PHP Markdown・Python-Markdown のエスケープ表には `<` と `&` が無い。Python-Markdown 3.11 の実測では、`Use \<script>alert(1)\</script>` が生の `<script>` 要素と余計な `\` になり、`\&copy;` は `\©` になった。RAG 側で広く使われる Python-Markdown では、今回の修正が守りたい「生 HTML を許可して描画する利用側」を守れない。readme の「a Markdown renderer shows those characters」も無条件の主張になっている。

**修正方針:** `<` → `&lt;`、`>` → `&gt;`、文字参照の形の `&` → `&amp;` にする（ユーザー判断で `>` も含める）。文字参照はどの方言でも文字として描画され、DOMDocument が無い環境のフォールバック（`fallback_plain_text()`）が残す `&lt;b&gt;` とも同じ形になる。`&` の置換は `<` / `>` の置換より前に行う（後にすると、足した `&lt;` の `&` まで `&amp;` になる）。テスト・DESIGN §7.3・CLAUDE.md・readme・backlog の記述を合わせて直す。既存テストの `\> literal`（`<p>&gt; literal</p>`）の期待値は `&gt; literal` に変わる。
