## 指摘
### [R1-1][Medium][plugins/saai-knowledge/includes/class-sidebar-tree.php:187]
`apply_expansion()` は `cached_skeleton()`（＝`get_transient()`）が返す配列を `&$node` で直接書き換える設計。PHPの配列COW（copy-on-write）により、`foreach ... as &$node` へ入る瞬間に参照カウント>1（オブジェクトキャッシュ内部の保持分と、返り値として渡ってきた分）であれば自動的に物理コピーが分離されるため、コード自身のコメント通り「他リクエストが読む共有キャッシュを破壊しない」は正しい（本レビューで検証済み）。ただし、この安全性を直接裏付けるテスト——同一プロセス内で `build()` を異なる `current_post_id`/`current_term_id` で連続呼び出しし、互いの `expanded` フラグが混線しないことを確認するテスト——が無い（`tests/test-kb-sidebar.php` の既存テストは全て `build()` を1回しか呼ばない）。将来のリファクタでこの前提（COWに依存した安全性）が壊れた場合に検知できない。
**修正方針:** `build()` を同一テスト内で異なる `current_post_id` により2回連続呼び出し、両方の `expanded` 結果が独立して正しいことを検証するテストを追加する。
