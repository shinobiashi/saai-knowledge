## 新規指摘（R1 修正差分が持ち込んだもの。いずれも本ラウンドで修正）

### [R2-1][Medium][plugins/saai-knowledge-for-woocommerce/tests/test-woo-product-page.php]
R1-1 のテストが修正を固定していない（`get_post()` 自身がミス時にキャッシュへ載せるため、プライミングを削除しても `wp_cache_get( ..., 'posts' )` は非 false）。
**対応:** 「記事 1 件の商品と 3 件の商品で、キャッシュを冷やしてから描画したときのクエリ数の差分が増えない」比較テスト `test_kb_links_prime_the_article_caches_in_one_go` に置き換え。ミューテーションで CAUGHT（`98f603c`）

### [R2-2][Medium][plugins/saai-knowledge-for-woocommerce/tests/test-woo-product-page.php]
REST ケースの `go_to( '?rest_route=...' )` は REST を再現しない（`rest_route` は `WP_UnitTestCase_Base::tear_down()` が `$wp = new WP()` で戻した後は public query var でなく、home クエリと等価。逆にプロセス先頭で走ると `rest_api_loaded()` が serve して die する実行順依存）。
**対応:** block-renderer が実際に残す状態 — `rest_api_loaded()` が `parse_request` 中に serve して exit するため `WP::main()` の main query は走らず `$wp_query` は空の `WP_Query` のまま、グローバル `$post` は `post_id` パラメータの商品 — を直接作って assert（`98f603c`）

### [R2-3][Low][plugins/saai-knowledge-for-woocommerce/includes/class-product-page.php]
「KB のパーマリンクはカテゴリーを埋め込む」というコメント（と R1-1 本文の同じ記述）が誤り。`saai_kb` の rewrite は `kb/{slug}` でタクソノミーを含まず、`_prime_post_caches( ..., true, ... )` の term プライミングは定数 1 本の余分なクエリだった。
**対応:** `_prime_post_caches( $kb_ids, false, false )` に変更しコメントを訂正（`98f603c`）

### [R2-4][Low][docs/DESIGN-AUTOLINK.md §6]
`wc_format_content()` 除外の副作用（テーマが `short-description.php` をオーバーライドして `wc_format_content( $post->post_excerpt )` 経由で出力すると表示用の短い説明までスキップされる）が未記載。
**対応:** 既知の制約として 1 文追記（`98f603c`）

## 確認済み（問題なし）

- `is_inside_wc_format_content()` の誤検知: 名前空間付き関数は `NS\wc_format_content` として現れ不一致、クラスメソッドは `isset( class )` で除外、クロージャは `{closure}`。グローバル同名関数は WC 本体と再宣言衝突するため実在しえない
- スタブ `tests/stubs/wc-format-content.php` は PHPCS（`<file>plugins</file>`）・PHPStan（`plugins/*`）・PHPUnit（`plugins/*/tests`）のいずれの範囲外で、`function_exists` ガード付きで `set_up()` から `require_once` するため将来 WooCommerce を bootstrap に足しても再宣言 fatal にならない
- `_prime_post_caches()` は WP 6.1 以降 private 扱いではなく、WooCommerce 自身も使用
- 再構築クエリ（R1-4 iii）は `fields` 未設定で `WP_Post` が返り、`render.php` の既定属性描画と整合
- 残る既知の限界（修正差分由来ではない）: priority 20 より後の第三者 `saai_faq_query_args` コールバックが `post__in` を落とす／非配列を返す場合はアドオン側では防げない
