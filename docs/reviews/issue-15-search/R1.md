## 指摘

### [R1-1][High][plugins/saai-knowledge/includes/class-search.php:~180-197]
`results()` が `get_the_title( $post )` と `wp_strip_all_tags( get_the_excerpt( $post ) )` を
HTML実体参照（`&#038;` 等）を含んだまま REST JSON レスポンスへ入れている。フロント
（`src/search/view.js` の `renderResults()`）は `link.textContent = result.title` /
`excerpt.textContent = result.excerpt` と DOM の `textContent` へ直接代入しているため、
ブラウザは実体参照をデコードせず、`"Widgets & Gadgets"` というタイトルが画面上
`"Widgets &#038; Gadgets"` とそのまま表示される（実機で確認済み。抜粋側も同様に
`"R&D"` が `"R&#038;D"` になる）。

`get_the_title()` の戻り値がHTML実体参照を含む前提で、それを非HTMLシンク
（JSON→JS textContent）へ渡す場合はデコードが必要という契約は、本プロジェクトの
`class-glossary-term.php:396-400`（JSON-LD向け出力で
`html_entity_decode( wp_strip_all_tags( get_the_title( $post ) ), ENT_QUOTES | ENT_SUBSTITUTE | ENT_HTML5, 'UTF-8' )`
を使用）で既に確立されているパターンと同一。

**修正方針:** `results()` の title/excerpt 生成箇所で同じ
`html_entity_decode( ..., ENT_QUOTES | ENT_SUBSTITUTE | ENT_HTML5, 'UTF-8' )` を適用する。
