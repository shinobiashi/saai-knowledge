## 指摘

### [G2-1][Codex][Medium][plugins/saai-knowledge/includes/class-markdown-converter.php:266]

`<div>prefix<div># literal</div></div>` は、R1-2 の `end_block()` で空行が入るようになり `prefix\n\n# literal` になって、文字だった `# literal` が見出しに変わる。`- item` はリスト、`---` は罫線になる。`default` で変換するブロック要素の直下のテキストには `escape_line_start()` が掛からないため（wp-env で再現）。/ 判定: 修正（この PR が持ち込んだ表示の後退）

**対応:** bd90c71 で直した。

- `convert_children()` が、出力が行頭に来るテキストノード（ブロック要素の直下の先頭、ブロックや `<br>` の後）の先頭の空白を落とし、`escape_line_start()` を掛ける。行頭の判定は `is_line_start_whitespace()` と共通の `at_line_start()` にまとめた
- `escape_line_start()` は `-` の後ろに `-` が続く場合（`---`）もエスケープする
- 番号付きリストは、数字ではなく区切りの `.` / `)` の前にバックスラッシュを置く（`1\. `）
  - バックスラッシュは記号の前でしかエスケープにならないので、従来の `\1. ` はバックスラッシュがそのまま表示されていた（main からの既存の不具合）
  - 行頭のエスケープを広げると、`<br>` の後に書いた `1. Install` の行にもこれが出るため、合わせて直した
- テスト `test_text_at_the_start_of_a_line_escapes_block_markers` を追加し、既存の `1. literal` の期待値を `1\. literal` に更新した
- ミューテーション3つ（行頭のエスケープを外す・番号を `\1.` に戻す・`---` を外す）がすべて CAUGHT
- 副次的に backlog R1-X1（issue-79）（`<br>` の後の `---` / `- bar`）が解消した
