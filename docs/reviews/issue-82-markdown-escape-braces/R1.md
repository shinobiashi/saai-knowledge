## 指摘

なし（Critical / High / Medium）。

確認した内容:

- 脅威の遮断: 見出し（h2 / h3）の末尾、`<br>` の後の段落の最終行、strong / a / code / img の直後、li（入れ子を含む）、th / td、blockquote、dt、figcaption、summary、div 直下の span、`<span>{</span>` によるノードの分割の 16 文脈を5描画系で描画し、onclick は 0 件（独立レビュー）。コードスパン・フェンスの中の `{` は attr_list の対象外
- 回帰: `\` を先に置換するので二重エスケープは起きない（`a\{b}` → `a\\\{b\}`）。`&#123;` は DOMText でデコード済みの `{` としてエスケープされる。行頭の `#{x}`、表、llms.txt の形も変わらない
- テスト: 新テストのうち convert と H1 の2件は、置換を外すと落ちる（ミューテーションで実測）。コードを非エスケープのまま出すテストは、修正の有無に関係なく通る仕様のガード
- Llms_Index・Markdown_Output・Export が組み立てる行のタイトル・ターム名・見出しは、すべて `escape_text()` を通る
