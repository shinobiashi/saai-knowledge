## 指摘

### [R2-1][Low][plugins/saai-knowledge/readme.txt / class-autolinker.php（`entry_excerpt()` の docblock）]

readme の「Links to such a term still appear」と docblock の「the link … stays」は、タイトルでもリンクが付くと読める。フロントエンドでは `get_the_title()` が `protected_title_format` を適用するので、保護された用語のタイトルのパターンは「Protected: タイトル」（ja では「保護中: タイトル」）になり、実際にリンクが付くのは同義語だけ（挙動自体は 1.0.0 から。この差分で入ったのは文言）。

**対応:** このラウンドで修正（readme・docblock・DESIGN-AUTOLINK §2.2 を「同義語でリンクされる」に）。タイトルのパターンに接頭辞が付くこと自体は backlog R2-X1（issue-56）

### [R2-2][Low][plugins/saai-knowledge/readme.txt]

「tooltips already saved by an earlier version are rebuilt when you update」はプラグイン自身のキャッシュについては正しいが、ページキャッシュや CDN に残った HTML の `data-saai-tooltip` はパージするまで残る。セキュリティ修正のリリースノートなので、管理者が残った漏洩に気づかないおそれがある。

**対応:** このラウンドで修正（「ページキャッシュを使っているサイトはキャッシュを消す」を追記）

## 確認して問題が無かった観点（独立レビュー）

- 空の抜粋の用語: `view.js` の `hasPreview()` が空文字を偽と見るので `show()` は何もせず、`handleClick` もタップを横取りしない（行き止まりにならない。DESIGN-AUTOLINK §3.3 と一致）
- `post_password` の型: DB の列は NOT NULL。null でも厳密比較なので TypeError にならず、隠す側に倒れる。`'0'` も隠す（安全側）
- テストの後始末: フィルターは `finally` で外し、投稿は1件ずつ削除
- 用語集の索引・llms・エクスポート・検索・FAQ リストはクエリで `has_password => false` を付けているので影響なし
