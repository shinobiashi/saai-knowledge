## 指摘

### [R1-1][High][plugins/saai-knowledge/includes/class-autolinker.php（`entry_excerpt()` / `build_dictionary_entries()`）]

差分範囲外（1.0.0 からの既存挙動）、ユーザー判断でこの PR に取り込む。パスワード保護された用語の本文が、自動リンクのツールチップ（`data-saai-tooltip`）で全訪問者に出る。辞書は `publish` の用語を全件対象にし、手動の抜粋が無ければ `post_content` を直接切るため。手動の抜粋がある場合も、パスワードを入力済みの閲覧者のリクエストで辞書が作られると、その抜粋が全員向けの辞書に入る。用語ページの JSON-LD は `post_password_required()` で守っている。dev サイトで再現（別表記で一致させると `data-saai-tooltip="TOP SECRET definition text."`）。

**修正方針:** 辞書はサイト全体で共有するので、閲覧者の Cookie で結果が変わる `post_password_required()` ではなく、`post_password` が空でない用語の抜粋を空にする（空の抜粋ではツールチップを出さない。リンクは残る）。1.0.3 で辞書が作り直されるので、既存サイトの辞書に入った本文も更新で消える。有料版の商品ページの用語集は `Link_Resolver` が既定で `has_password => false` を付けて引くので該当しない（商品ページのツールチップは無料版の辞書を使うのでこの修正で直る）。
