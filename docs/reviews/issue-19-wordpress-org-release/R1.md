## 対象外指摘（差分範囲外）

- [R1対象外-1][Medium][plugins/saai-knowledge/includes/class-autolinker.php（`entry_excerpt()`）]
  `wp_trim_words( $post->post_content, 55 )` は、サイトロケールが `wp_get_word_count_type()` で文字数カウント型を
  返す言語（例: `ja`）の場合「55単語」ではなく「55文字」で切り詰める。日本語管理画面で英語の用語集定義を登録すると、
  自動リンクツールチップの抜粋が単語の途中で切れる（例: "...passwor&hellip;"）。今回の差分（テンプレートの余白修正）
  とは無関係な既存コードの不具合。前セッションでユーザーに報告済み、対応要否は未確定。
