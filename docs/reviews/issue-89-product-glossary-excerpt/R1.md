## 指摘

### [R1-1][Medium][plugins/saai-knowledge-for-woocommerce/tests/test-woo-plain-excerpt.php]

照合テストが固定の入力の結果を比べるだけで、複製のずれの多くを見逃す（独立レビューで実測。`\p{Hangul}` の追加、`\p{Lao}` / `\p{Khmer}` / `\p{Myanmar}` の削除、空白の畳み込みへの `\f` の追加、`ENT_HTML5` → `ENT_HTML401`、`\x{30FC}` の削除などが green のまま）。範囲を狭める改変は、このサーバーの PCRE が `\p{Han}` / `\p{Katakana}` の Script_Extensions で同じ文字を拾うため、結果の比較では原理的に捕まらない。それでも docblock・DESIGN.md・i18n.md は「片方を変えると照合テストが落ちる」と書いていた。

**修正方針:** 両クラスの `NO_SPACE_CHARACTERS` / `UNIT_PATTERN` を `ReflectionClassConstant` で比べ、`trim_words()` / `plain_text()` の本体を空白・コメントを除いたトークンで比べるテスト（`test_copies_the_free_plugin_code`）を足す。結果の比較には韓国語が先頭の文・ラオ・クメール・ミャンマーの文・`&apos;` と `\f` を含む文を足す。docblock・DESIGN.md・i18n.md・backlog の記述を合わせる。
