## 指摘

### [R1-1][Medium][plugins/saai-knowledge/tests/test-settings.php:145-158]
`test_post_type_rewrite_slug_reads_the_settings_option()` が `saai_kb` の rewrite slug を
`'articles'` に変更した後、テスト末尾で `delete_option()` + 再登録によって既定値
（`'kb'`）に戻していたが、この復元コードは `assertSame()` が失敗した場合に実行されない。
`register_post_type()` の登録先はDB（トランザクションロールバック対象）ではなく
プロセスグローバルなPHPレジストリのため、アサーション失敗時に `saai_kb` の slug が
`'articles'` のまま同一PHPUnitプロセス内の後続テストに漏れ、無関係なテストが
原因不明に落ちるリスクがあった。

**修正方針:** 復元処理を `try/finally` に包み、アサーション成否にかかわらず必ず
既定値へ再登録するようにした。
