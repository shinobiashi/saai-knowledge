## 指摘

### [G2-1][Codex][Medium][plugins/saai-knowledge-for-woocommerce/assets/js/product-links-metabox.js:253]

商品は編集できるがリンク先コンテンツは編集できないロールで、一覧は `read_post` で絞るため
他人の公開投稿が載る一方、`Unlink` ボタンは無条件に描画されていた。解除は `edit_post` を要求するので
**押すと必ず 403 になる操作**を提供していた。

前提の実機確認: 他人の公開 FAQ に対し `read_post=true` / `edit_post=false`（PHPUnit で実測）。

判定: 修正
**対応:** `can_edit` フィールドを追加し、偽なら `Unlink` を描画しない。一覧のフィルタは `read_post` のまま
（その商品に効いているコンテンツは変更できなくても見えるべき）。ミューテーション（`can_edit` を `true` 固定）で
`test_edit_link_is_empty_without_edit_permission` が落ちることを確認（`a933fc6`）/
スレッド: https://github.com/shinobiashi/saai-knowledge/pull/64#discussion_r4093011805

### [G2-2][Codex][Medium][plugins/saai-knowledge-for-woocommerce/includes/class-links-controller.php:349]

同じ非対称が検索側にも。候補は `read_post` で絞られるが、選択後の POST は `edit_post` を要求するため、
**選んでも必ず失敗する候補**が出ていた。

判定: 修正
**対応:** `visible_items()` に capability 引数を追加し、検索だけ `edit_post` に切り替え。
ミューテーション（`read_post` に戻す）で `test_content_search_only_suggests_editable_content` が
落ちることを確認（`a933fc6`）/
スレッド: https://github.com/shinobiashi/saai-knowledge/pull/64#discussion_r4093011821

### [G2-3][Copilot][Low][plugins/saai-knowledge-for-woocommerce/includes/class-link-resolver.php:207]

`link_product()` の冪等性判定が read→add の2段階のため、同時 POST で重複行が生まれうる。

判定: **保留**（指摘は正しいが原子的に直す手段が無い）。`wp_postmeta` に (post_id, meta_key, meta_value) の
一意制約は無く、`add_post_meta()` の `$unique = true` は meta_key 単位の一意性しか見ないため多値キーには使えない。
DB ロック導入はこの機能の規模に見合わない。
**対応:** 重複行が無害かつ自己修復することをテストで固定（読み取りは `array_unique` と `GROUP BY` で全て畳み、
`unlink_product()` は一致行を全削除するため1回の解除で解消する）。あわせて DESIGN.md §6.1 の「1値1行」が
**保存形式の規約**であって行の一意性保証ではないことを明記（`a933fc6`）/
スレッド: https://github.com/shinobiashi/saai-knowledge/pull/64#discussion_r4093020428
