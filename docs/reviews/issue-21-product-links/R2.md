## 本ラウンドで見つかった問題と対応

### R1-L6 の修正が no-op だった（自分の誤り）

`ComboboxControl` に `disabled` プロパティは**存在しない**。WP 7.1.2 同梱の
`wp-includes/js/dist/components.js:38443-38461` を自分で確認したところ、固定のプロパティ一覧を
分割代入するだけで残りを DOM へ渡す経路も無く、`disabled: busy` は黙って捨てられていた。
R1 のコミットメッセージはこれを「修正した」と書いており、事実と違っていた。

対応: 対応プロパティである `isLoading: busy` に変更し、実効的なガードを `onChange` 冒頭の
`if ( busy ) { return; }` に置いた。
