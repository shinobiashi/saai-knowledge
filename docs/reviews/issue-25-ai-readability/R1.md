## 指摘

### [R1-1][Critical][plugins/saai-knowledge/includes/class-markdown-output.php:64-92]
`Markdown_Output::maybe_serve()` は `post_status === 'publish'` のみを確認しており、
`post_password_required( $post )` のチェックが無い。WordPress core のパスワード保護機能
（`post_password`）が設定された saai_faq/saai_kb/saai_glossary 投稿は、通常のHTML表示では
パスワード入力フォームに置き換えられる（`get_the_password_form()`）が、
`?format=markdown` 経由では `$post->post_content` をそのまま Markdown 化してしまうため、
パスワード保護を完全にバイパスして本文が誰でも閲覧できてしまう。

同じプロジェクト内でも `Search::results()` は `has_password: false` を `WP_Query` に
明示しており、`Llms_Index::collect_items()` も同様に `has_password: false` を設定済み
（インデックス一覧には漏れない）。`Glossary_Term::append_after_definition_hook()` も
`post_password_required( $post )` を明示チェックしている。この既存パターンだけが
`Markdown_Output` に欠けている。

**修正方針:** `maybe_serve()` の投稿ステータス確認の直後に
`post_password_required( $post )` を確認し、真なら通常テンプレートへフォールスルーする
（return する）。
